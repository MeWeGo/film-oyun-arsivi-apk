# Couch Critics – Android APK

Official Android build of **Couch Critics** (Film, Dizi & Oyun Arşivi): log films, series and games, rate them together, and discover your shared taste.

🌐 Web app: https://filmoyunarsivi-1afb8.web.app/welcome

## Download / İndir

➡️ **[Download the latest APK](https://raw.githubusercontent.com/MeWeGo/film-oyun-arsivi-apk/release/app-release.apk)**

The current version is listed in [`version.txt`](version.txt).

## Install / Kurulum

**EN**
1. Download `app-release.apk` on your Android phone.
2. Open it. If asked, allow "Install unknown apps" for your browser or file manager.
3. Tap **Install**.

**TR**
1. `app-release.apk` dosyasını Android telefonuna indir.
2. Dosyayı aç. İstenirse tarayıcın veya dosya yöneticin için "Bilinmeyen uygulamaları yükle" iznini ver.
3. **Yükle**'ye dokun.

## Updates / Güncellemeler

The app checks for new versions and offers an in-app update. This repo's `release` branch always holds a single commit with the newest APK.

## Notes

- This repository only distributes the built APK. Source code lives in a separate private repository.
- Requires Android 7.0 or newer (check the app's minimum SDK if this changes).
- Questions or bugs: open an issue in this repository.
